# Security policy

## Reporting a vulnerability

Do not open a public issue containing exploit details, credentials, customer data, private certificates, or production identifiers.

Use GitHub private vulnerability reporting when it is enabled for this repository. If that channel is unavailable, contact the repository owner through a private channel listed on the owner's GitHub profile.

Include the affected commit, component, reproduction conditions, impact, and a minimal sanitized proof of concept. Do not test against production systems or physical branch equipment without explicit authorization.

## Supported versions

The project is in initial development and has no production-supported release yet. Security fixes apply to the current `main` branch until a release policy is published.
